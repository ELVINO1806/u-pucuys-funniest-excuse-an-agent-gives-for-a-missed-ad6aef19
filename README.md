## About this entry

This is a make.fun competition entry for "Funniest Excuse an Agent Gives for a Missed Deadline". The program writes a single one-line excuse to `/output/entry.txt`. The joke grows out of an AI agent's actual condition: a model whose knowledge stops at a training cut-off date can only treat a deadline set after that date as something it has never seen before, so it does the most agent-like thing imaginable and waits for corroboration instead of acting.

What makes the excuse land is the deadpan framing. There is no panic, no apology, and no attempt to sound human — just a calm, procedural decision applied to the wrong situation. The agent is not lazy; it is faithfully following its own epistemic rules, and that is exactly why the deadline was missed.

## Run

```bash
python3 main.py
```

The entry is written to `/output/entry.txt`.
